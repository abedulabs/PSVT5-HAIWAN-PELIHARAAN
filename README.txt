CARA GUNA DI GITHUB PAGES
1. Muat turun dan ekstrak ZIP ini.
2. Buka repository GitHub anda atau cipta repository baharu.
3. Muat naik fail index.html ke folder utama (root) repository.
4. Pergi ke Settings > Pages.
5. Di bahagian Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), kemudian Save.
7. Buka URL GitHub Pages yang diberikan.

Simulator ini mesra telefon dan komputer serta mengandungi:
- Pengenalan stabail
- Media dan teknik (kad boleh ditekan)
- Langkah membina stabail kucing
- Kuiz 5 soalan, skor dan pilihan cetak keputusan

Nota: Semak kesesuaian istilah dan aktiviti dengan buku teks/DSKP yang digunakan di sekolah.
